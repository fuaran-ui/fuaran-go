# Conformance residue — the named, current set of failing tests in this host.
#
# WHAT THIS IS. Every line names one test (or subtest) that fails against the
# CURRENT shared corpus on a clean tree. `cmd/conformance-residue` runs the whole
# suite with no exclusions and compares what actually failed against this list:
#
#   * a failure NOT on this list is a REGRESSION      -> red, named;
#   * a line on this list that now PASSES is STALE    -> red, named, delete it.
#
# Red in both directions is the whole point. It replaces a `go test -skip`
# quarantine that could only ever be wrong in the second direction silently: the
# patterns it carried named `form-toggle`, `now-environment-binding` and
# `switch-on-selection`, which the decoder adopted on 2026-08-11, so by the time
# this file was written the quarantine excluded eight WHOLE tests to suppress
# three fixtures that had passed for weeks — and in doing so hid nine real
# failures it never named. A stale exclusion is worse than no exclusion, because
# it reads as a measured cap.
#
# HOW TO SHRINK IT. Fix the decoder, delete the line, and the gate stays green.
# There is no way to make this file grow that does not show up in a diff.
#
# A bare `go test ./...` still runs the suite RAW and reports a listed failure as
# an ordinary one: this file caps what BLOCKS, never what is reported. Since
# Phase 1673 `pwsh ./run.ps1` is NOT in that category — its test stage is this
# gate, so the launcher and CI block on the same set (see run.ps1).
#
# ── The set is EMPTY, and that is a measurement rather than an omission ──────
#
# Every entry this file once carried now PASSES. The list is kept — with its
# rules above intact — because the gate reads it on every run: an empty set says
# "nothing is permitted to fail", which is a stronger claim than the file's
# absence would make, and the regression direction still goes red by name.
#
# CLOSED, in the order the gate reported them:
#
# (a) Now.grain — 2026-09-06. The decoder adopted `grain` on main while this file
#     was being written; the STALE half reported it on the first merge after the
#     gate landed.
# (b) astral-plane object keys (TestRoundTrip/custom-nonascii-keys)
# (c) encoding/json repairing what the wire format refuses — the four reject
#     vectors for duplicate object keys and for lone or split surrogates
# (d) the §1521 integer lenience rules — an integral float in an int slot, and an
#     integer beyond 2^53 normalised to the boundary value
#
#     (b), (c) and (d) were closed together by the decode-determinism adoption
#     (`feat(wire): adopt the ratified decode-determinism rules on this host`,
#     2026-09-06), which landed minutes after this file was written and made
#     seven of its eight lines stale at once. The gate said so, by name, on every

#     nobody deleted them. Phase 1673 did. That six days is the estate's own
